# Projeto de Desenvolvimento Web | e-commerce

**Objetivo**

Desenvolver uma loja virtual completa.

**Justificativa**

Um e-commerce é mais que uma página da web estática, é uma página dinâmica que permite que cada usuário tenha seu cadastro e ambiente privativo, além disso um site de loja virtual integra sistema de cadastro, login e recuperação de senha, banco de dados, insersão e controle de estoque de produtos, pagamento e rastreamento de entregas.

**Sobre o projeto**

A ideia do projeto veio após conclusão do módulo de Desenvolvimento Web, na faculdade, que envolveu HTML, CSS, JavaScript e PHP. E o tomei como um deafio que, aos poucos, eu vou construindo e aprimorando.

## Etapas 

Fase 1. Desenvolvimento de página simples em HTML e CSS contendo Cadastro, Login, Carrinho de Compras, Formas de Pagamento e Itens a venda. 

Status: Concluído

Próxima etapa: Aprimoramento do HTML e CSS e inicio de criação de regras para cadastro e login simples.
